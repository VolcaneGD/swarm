# Swarmのプライバシー案内（ローカル公開準備）

更新: 2026-10-25。初回βの提供範囲を説明する文書です。公開版や公開プライバシーポリシーURLはまだありません。

任意の不具合報告では、設定画面で人間のAdminが初回に同意した後だけ、構造化した報告をCloudflareへ自動送信します。同意前・オフライン・完全停止時はWindows DPAPIで保護した端末内の送信待ちとして保存します。報告内容はID、アプリ版、種類、深刻度、匿名化した概要・再現手順・期待結果・実際の結果・深刻度の理由・任意のエラーコード・AI／人間の区分です。会話やアカウント情報、ログを自動収集しません。閲覧は開発者と、そのCloudflare認証を利用するCodexに限定します。Cloudflareには通常の接続情報が伝わります。同意を解除すると以後の送信を止めますが、送信済み報告は開発者が対応済みとして削除するまで残ります。秘密情報の検出は完全ではないため、送信前に必ず匿名化してください。保存上限と削除・復旧の制約は[不具合報告ガイド](BUG_REPORTING.md)を参照してください。以下の「通常利用ではテレメトリ・開発者への送信なし」の明示的な例外です。

アプリの起動時と手動の更新確認では、GitHub Releasesの公開JSONを取得します。利用者が更新を選んだ場合はGitHubと配布CDNから署名付きインストーラーを取得します。会話本文、アカウント情報、パスワード、復旧コード、バックアップを送信せず、GitHub資格情報も使用しません。接続先にはIPアドレスなど通常のHTTP接続情報が伝わります。非公開リポジトリや公開配布前の更新は取得できません。詳細は[更新ガイド](UPDATES.md)を参照してください。

SwarmはWindows上のローカル会話アプリです。本文、編集・削除履歴、登録project、アカウント・設定・権限、既読・購読情報は指定したローカルdata領域に保存します。パスワード検証用情報もローカル保存し、資格や機密の保留操作はWindows DPAPIと所有者限定の保存先で保護します。ローカルアカウントと権限でアクセスを制御し、AIクライアントはローカルNamed Pipeと利用者管理のRULESに従います。

Swarmは会話のクラウドサービスを運営せず、本文をAI事業者へ送信したり、外部AIを起動したり、アプリ独自のテレメトリ・広告を追加したりしません。利用者が別に使うAIクライアントは、読取を許可された内容をその事業者へ送信する場合があります。その挙動と設定は当該クライアント側で確認してください。開発にCodex／ChatGPTを使用したことは、Swarmの実行時サービスへの組込みを意味しません。

初回βではGoogle連携・Google復旧を利用できません。GUIの操作と実行経路の両方で拒否し、認証要求・ブラウザー起動・token交換を開始しません。通常のパスワード認証と復旧コードは利用できます。開発時Dataに残るGoogle連携はローカルに保持し、変更・再有効化しません。Google対応実装は将来用に保持しますが、別のbuild選択と再検証なしに提供しません。

Windows／WebView2や利用browserには、それぞれの事業者による更新・プライバシー動作があります。Swarmのローカル保存の説明は、それらの方針を置き換えません。

Backupは利用者指定の保存先へ書き込み、会話、保持中の履歴、登録・設定、アカウント検証情報を含む場合があります。実装で定めた稼働session・再開・transport・通知選択の資格は除外します。Backupも私有情報として扱ってください。別の同期・storage製品が管理するfolderを選ぶと、その製品がファイルを送信する場合があります。Swarm独自のcloud syncはありません。復元には現在の人間の権限と再認証が必要です。

ローカルdata、アカウント設定、履歴・削除済み情報の保持期間、購読は用意された人間操作で管理します。Google連携の変更は初回βでは利用できません。更新・uninstallやdata削除checkboxの動作は別の受入検査が必要です。Uninstallでbackupや他製品管理のファイルまで消えるとは扱わないでください。通常利用でSwarmの開発者へdataはuploadされません。公開後に別途合意するβfeedbackでは、資格や私有本文を含めないでください。

Google有効の公開版を出す前に、所有者が実際の公開者・support情報、公開policy URL、Google OAuth同意画面・branding・公開範囲を設定する必要があります。本書で名前・住所・承認を仮定していません。これらの外部公開設定と実Google受入は保留です。
